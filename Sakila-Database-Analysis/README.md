# Sakila Database Analysis using MySQL

## Project Overview

This project is based on the Sakila sample database in MySQL. I worked on a set of SQL questions to explore customer rental activity, film categories, store performance, rental income and actor participation.

## Database

**Sakila Sample Database**

The database contains information about films, customers, actors, stores, rentals, inventory and payments.

## Analysis Performed

| No. | Analysis |
|---|---|
| 1 | Customer rental details |
| 2 | Customers from selected districts |
| 3 | Films and their categories |
| 4 | Rental count by store |
| 5 | Categories with more than 50 films |
| 6 | Films rented by Mary Smith |
| 7 | Rental income by film |
| 8 | Number of films by actor |
| 9 | Customer classification using CASE |
| 10 | Films with titles starting with A |

I also practised creating a database, inserting records, modifying a table and dropping database objects.
